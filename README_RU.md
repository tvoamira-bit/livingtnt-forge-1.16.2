# Living TNT — Minecraft Forge 1.16.2\n\nДобавляет 20 динамитов, создающих готовые постройки с интерьером.\n\n## Постройки\n- Домик (`house_tnt`)\n- Лесная хижина (`cabin_tnt`)\n- Замок (`castle_tnt`)\n- Особняк (`mansion_tnt`)\n- Бункер (`bunker_tnt`)\n- Японская пагода (`pagoda_tnt`)\n- Уютный коттедж (`cottage_tnt`)\n- Каменный дом (`stone_house_tnt`)\n- Еловый дом (`spruce_house_tnt`)\n- Берёзовый дом (`birch_house_tnt`)\n- Дом в джунглях (`jungle_house_tnt`)\n- Пустынный дом (`desert_house_tnt`)\n- Снежный дом (`snow_house_tnt`)\n- Дом на болоте (`swamp_house_tnt`)\n- Фермерский дом (`farm_house_tnt`)\n- Сторожевая башня (`tower_house_tnt`)\n- Башня мага (`wizard_tower_tnt`)\n- Маяк (`lighthouse_tnt`)\n- Современный дом (`modern_house_tnt`)\n- Дом на дереве (`treehouse_tnt`)\n\n## Сборка\nТребуются Minecraft 1.16.2, Forge 33.0.61 и JDK 8. Выполните `gradle build`; JAR появится в `build/libs/`.\n\n## Важно\nЭто исходный проект, JAR не собран и не проверен запуском в Minecraft. Тестируйте в отдельном мире.\n
