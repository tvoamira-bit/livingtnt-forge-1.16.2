КАК ПОЛУЧИТЬ JAR БЕЗ УСТАНОВКИ JAVA И GRADLE

1. Зайди на https://github.com и войди в аккаунт (или зарегистрируйся).
2. Создай репозиторий: https://github.com/new
   Назови, например, livingtnt-forge-1.16.2. Можно выбрать Public или Private.
3. Распакуй этот ZIP на компьютере.
4. В новом репозитории нажми Add file -> Upload files.
5. Перетащи ВСЁ СОДЕРЖИМОЕ папки livingtnt-1.16.2 в окно загрузки.
   Важно: загрузи папку .github тоже. В ней лежит workflow сборки.
6. Нажми Commit changes.
7. Открой вкладку Actions. Выбери Build Minecraft Forge Mod.
   Если сборка не стартовала сама, нажми Run workflow -> Run workflow.
8. Дождись завершения. Если всё успешно, открой запуск с зелёной галочкой.
9. Внизу страницы найди Artifacts и скачай livingtnt-forge-1.16.2.
10. Распакуй скачанный архив. Файл .jar положи в .minecraft/mods.
11. Запусти Minecraft Java Edition 1.16.2 с профилем Forge 33.0.61.

Если в Actions красный крестик, открой Build mod, скопируй текст ошибки
или пришли скриншот — по нему можно понять, что нужно исправить.

Примечание: этот ZIP содержит исходный проект и автоматический сценарий сборки,
а не готовый проверенный JAR. В моде заявлены 20 видов TNT-домов.
